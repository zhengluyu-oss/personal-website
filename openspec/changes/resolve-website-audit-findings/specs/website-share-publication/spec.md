## ADDED Requirements

### Requirement: 公开网站分享必须有封面
网站分享处于公开状态时，管理端和后端 SHALL 要求非空的封面地址；草稿 SHALL 允许封面为空。该规则 MUST 在新增和更新时同样生效，不能通过直接调用 API 绕过。

#### Scenario: 保存无封面的草稿
- **WHEN** 管理员保存封面为空且状态为草稿的网站分享
- **THEN** 保存成功，记录仍为草稿

#### Scenario: 发布无封面的分享
- **WHEN** 管理员将封面为空或只有空白字符的分享设为公开并保存
- **THEN** 管理端提示需要封面，后端拒绝该发布请求并返回明确原因

#### Scenario: 直接调用接口发布
- **WHEN** 客户端绕过管理页面直接提交状态为公开且无封面的新增或更新请求
- **THEN** 后端拒绝请求，原有记录状态与内容不被部分更新

#### Scenario: 发布有封面的分享
- **WHEN** 管理员提交非空封面地址及其他有效内容并设为公开
- **THEN** 保存成功，前台列表与详情呈现该封面

### Requirement: 已有无封面公开记录得到处理
上线新发布规则前 SHALL 盘点已有公开且无封面的网站分享，并为每条记录补充真实封面或转为草稿；处理过程 MUST 保留记录正文与其他内容。

#### Scenario: 发现历史无封面公开记录
- **WHEN** 发布前盘点发现状态为公开且封面为空的记录
- **THEN** 记录进入待处理清单，在补图或转草稿前不得宣称数据已满足新规则
