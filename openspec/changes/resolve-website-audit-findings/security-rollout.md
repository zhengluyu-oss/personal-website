# 主安全链发布核对

规则版本：`main-allowlist-v1`，实现集中在 `blog-backend/src/main/java/xyz/luyu/config/SecurityConfiguration.java`。日记和知识库的专用安全链保持原样。

## 发布前已完成

- 按 HTTP 方法核对 `endpoint-inventory.md` 的公开文章、分类、标签、经历、站点信息、网站分享、登录注册、验证码和 OAuth 映射。
- `SecurityAllowlistTest` 验证匿名可读、登录用户仍被后台权限拦截、授权管理员可读后台、未知映射与新增 `/menu/**`、`/user/auth/**` 路径默认拒绝。
- `LoginFailureReasonSecurityTest`、OAuth 现有测试、日记与知识库专用链测试均包含在完整后端测试中；在 Windows 修正临时目录后，474 个测试无失败或错误。
- 生产前后台均通过同源 `/api` 代理调用后端；路由校验和前后台正式构建已通过。

## 部署后快速验收

1. 匿名访问首页、博客列表和文章详情、网站分享列表和详情；分别核对公开 GET 接口返回 200。
2. 匿名打开登录、注册和重置入口，提交测试账号的登录流程；验证码发送与送达状态应可访问。
3. 从登录页启动 Gitee 和 GitHub OAuth，确认浏览器可跳转提供方并正常返回回调页面。此项需要部署环境的 OAuth 凭据与回调域名。
4. 普通账号访问后台管理接口应被拒绝；有对应权限的管理员进入网站分享和文章编辑页应正常加载。
5. 未登记的新接口路径，即使带有效登录态也应被拒绝；日记和知识库仍由其专用规则决定。

若验收发现公开接口被误拦，先回退本次发布中的 `SecurityConfiguration.java` 至上一版并单独重建后端，再补全路径和方法的测试。网站分享封面校验与前端构建门槛无需随主安全链一同回退。
