## Context

生产环境已有日记问答和复盘任务因 `QUOTE_MISMATCH` 失败：模型生成的文字与来源原文不完全相同，严格的 `contains(quote)` 校验拒绝结果。索引已就绪，失败不是用户选择范围或索引缺失造成。当前后端使用 DeepSeek 生成，最多 2000 输出 token、单次请求、既有预算与租约；失败输出通过本人专属诊断最多保存七天。日记包日志默认关闭，因此生产排障只能依赖已保存的任务诊断。

## Goals / Non-Goals

**Goals:**

- 降低模型改写引文导致的问答、选篇复盘和期间复盘失败，同时保持逐字证据与来源类型校验。
- 让模型只能选择服务端给出的合法引文标识，由服务端恢复原文和来源绑定；资料不足时明确表达局限。
- 记录无私密正文的阶段、失败类别、耗时和用量，支持上线后的故障定位。
- 使用不超过现有资源和费用预算的测试与生产验收路径。

**Non-Goals:**

- 不放宽逐字引文要求，不将近似字符串自动改写为“有效证据”。
- 不新增模型、第二次付费请求、数据库表、附件能力或前端大改版。
- 不自动修复已失败的历史任务，也不保证有合法引文的模型解释一定正确。

## Decisions

### 服务端构造有界引文目录

在准备来源快照时按原文段落或句子边界产生短引文候选，每项携带不可由模型指定的来源 ID、类型、版本、精确原文和任务内稳定标识。目录受既有提示总长度限制；超出预算时不截断复盘的完整来源，优先压缩目录或在发起云端请求前明确拒绝。模型只返回引文标识，后端从当次可信目录恢复原文，校验标识归属、来源版本与证据类型，并沿用原有完整来源集合摘要与发布前检查。问答使用检索命中的来源；完整复盘仍保留完整合法资料。与允许模型写自由引文后做模糊匹配相比，这避免把改写甚至虚构内容误认为来源原文。

### 结论与证据分别校验

模型输出继续区分观察、推测、建议和局限。需要证据的结论必须引用目录中的合法标识；未知、跨任务、错类型或重复无效标识产生固定诊断，不发布结果。没有足够证据时模型必须收窄结论并说明缺口；服务端不得为了凑成功而替模型选择引文或把缺证据结论转成已证实事实。恢复出的原文仍通过既有逐字校验。与直接取消引文校验相比，此法保留用户可核对性。

### 兼容性和可观测性

新生成任务使用版本化响应契约；已存的成功报告与历史失败任务继续按原状态读取，不重新生成。继续使用现有七天诊断表保存不合格回答，只增加固定原因与字段路径。新增专用安全审计记录，限于任务 ID、类型、阶段、固定错误码、耗时、token 数和是否可能计费；不写原文、候选引文、模型输出、提示词、密钥、供应商响应体和堆栈。生产仅开放该审计记录的明确 logger，日记包其他日志保持关闭。

## Risks / Trade-offs

- [引文目录覆盖不足] → 用跨段落、长短文本和来源类型的固定样例校准候选边界；缺少合适证据时诚实失败或说明局限，不断言完整月度结论。
- [目录增加提示长度] → 复用现有总字符预算、预提交长度检查和模型输出上限，不扩容、不截断完整复盘来源。
- [模型选对引文却解释过度] → 保持语义限制和本人验收样例；界面仍提示引用正确不等于解释正确。
- [切换契约导致格式失败] → 版本化解析，覆盖空响应、截断、错类型、未知标识和多证据类型测试；不自动重试。
- [排障日志泄露隐私] → 日志字段白名单和测试断言，不记录自由文本或异常堆栈。

## Migration Plan

1. 本地实现并用虚构日记、长篇复盘、被修改来源、恶意内容及供应商异常响应测试；验证现有问答、复盘、预算、取消和七天诊断回归。
2. 发布前核对当前生产未结束 AI 任务和配置，备份可回滚后端构建；该变更不执行数据库迁移。
3. 在低使用时段发布后端并验证健康、索引和只读任务状态。由本人明确触发少量问答与复盘，分别检查逐字引用、实际费用/额度、局限说明和安全审计日志；不能把本地模拟通过当作真实模型验收。
4. 若格式失败率、隐私或任务状态出现回归，停止新生成并回滚后端构建；已发起的请求保留原任务终态，不自动重发。旧报告与诊断继续可读。

## Open Questions
