## Context

博客前台采用 Vue 3、SCSS、Element Plus 与 CSS 变量主题。首页当前由全屏品牌区、内容主栏、推荐文章 Swiper、文章列表与侧栏组成；工作经历已有列表、详情和 Markdown 渲染能力。本次设计跨越首页和经历页，但不改变任何数据契约，核心约束是保留推荐轮播的加载与交互逻辑。

## Goals / Non-Goals

**Goals:**

- 通过更强的排版尺度、留白、色彩光晕、玻璃质感和微交互建立一致的个人品牌视觉。
- 让首页公告、推荐内容、文章流和侧栏在宽屏上更有秩序，在窄屏上自然堆叠。
- 让工作经历成为清晰的职业叙事：先给出概览，再按时间浏览每段经历，并能进入图文详情。
- 复用现有主题变量、组件与图标，保证明暗主题和移动端可用。

**Non-Goals:**

- 不改动 Swiper 的接口请求、模块、自动播放、分页、导航、循环和跳转逻辑。
- 不改动后端、数据库、管理端、路由路径或 Markdown 内容模型。
- 不引入新的 UI、动画或字体依赖。

## Decisions

1. **首页采用“编辑部首页”视觉语言。** 在现有主栏内增加轻量引导区和统一 section heading，使用大字号衬线风格标题、细粒度标签、渐变光晕和柔和边框，避免推翻全屏 Brand 与 Layout 架构。相比重写整页，这种方式风险小且能保留既有内容流与侧栏。

2. **Swiper 只改模板展示层与 SCSS。** 保持脚本中的请求、过滤、模块和配置不变；幻灯片改为带遮罩的全幅封面、编号、标题、日期、摘要和明确的阅读提示。这样既满足保留代码要求，也显著增强首屏焦点。

3. **经历列表采用双栏职业旅程。** 宽屏左侧为 sticky 概览，右侧为带连续轨道和序号的经历卡片；窄屏退化为单栏。相比传统居中时间线，这一布局更像作品集并能容纳更丰富内容。

4. **动画仅使用 CSS 且尊重减少动画偏好。** 卡片进入、悬浮和背景漂移保持克制，并在 `prefers-reduced-motion` 下关闭，避免额外依赖与可访问性问题。

5. **详情页复用列表视觉标记。** 返回链接、时间徽章、公司与职位标题、摘要和 Markdown 纸张容器采用同一套颜色、圆角和边框，让导航前后具有连续性。

## Risks / Trade-offs

- [视觉效果依赖封面图片质量] → 使用渐变遮罩、背景色与文本阴影保证低质量或加载失败时仍可读。
- [大字号和装饰可能挤压移动端] → 在 900px 和 640px 断点调整字号、间距和网格，并隐藏非必要装饰。
- [主题变量覆盖范围不完整] → 颜色优先使用现有主题变量，固定品牌色仅用于小面积强调，并为深色背景提供专用透明度。
- [复杂动画影响性能] → 只动画 transform/opacity，限制光晕数量，减少动画模式下全部关闭。

## Migration Plan

直接替换前台 Vue 组件的模板和局部样式，运行类型检查与生产构建后部署静态资源。回滚时恢复这些前台组件即可，不涉及数据迁移。

## Open Questions

无。现有个人文案、文章数据和工作经历数据均继续作为内容来源。
