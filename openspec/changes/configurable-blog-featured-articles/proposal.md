## Why

博客聚合页和分类页当前将查询结果中的第一篇文章作为视觉主推荐，后台无法明确控制展示内容，且分类页在缺少稳定排序时可能出现不可预测的推荐结果。需要把“页面主推荐”变成独立、可管理且具有可靠兜底规则的内容配置能力，同时避免改变现有文章推荐功能的语义。

## What Changes

- 在后台网站管理中增加博客聚合页主推荐文章配置，并限制只能选择已发布文章。
- 为每个文章分类增加独立的分类页主推荐文章配置，并限制候选文章属于该分类且已发布。
- 聚合页和分类页优先展示各自配置的主推荐文章；未配置、文章已删除、取消发布或不再属于对应分类时，自动回退到最新已发布文章。
- 保留文章现有 `isTop` 推荐能力，不将其复用为页面唯一主推荐，避免影响已有推荐列表或首页业务。
- 调整聚合页与分类页的数据返回和前端展示逻辑，保证主推荐文章不会在下方普通列表中重复出现。
- 增加安全的可空字段迁移及配置校验，不要求为现有数据补值。

## Capabilities

### New Capabilities

- `configurable-blog-featured-articles`: 定义聚合页全局主推荐、分类页独立主推荐、后台选择约束、失效兜底及去重展示行为。

### Modified Capabilities

- 无。

## Impact

- 后端：网站信息、文章分类实体与 DTO、数据库迁移、管理端配置接口、公开文章聚合查询及校验逻辑。
- 管理端：网站管理中的聚合页主推荐选择器，以及分类管理中的分类推荐文章选择器。
- 博客前端：`/blog` 和 `/blog/:slug` 的主推荐解析、普通文章列表去重与空状态展示。
- 数据库：新增可空的文章引用字段；迁移保持向后兼容，旧数据继续采用自动回退规则。
- 现有文章详情路由、文章 API 路由层级及 `isTop` 推荐功能不改变。
