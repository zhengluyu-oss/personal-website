- [x] 1.1 依据现有知识库样本建立覆盖中文改写、同义表述、跨段归纳、无答案和指代追问的标注问答集，记录预期证据与拒答结果。
- [x] 1.2 对拟修改的客服及知识库检索符号运行 GitNexus upstream impact，记录调用者、流程和风险；核对现有权限、版本及额度测试。

## 2. 客服专用证据检索

- [x] 2.1 实现有固定查询与候选上限的问题规范化、短语和词项生成，避免长中文串被机械截成单一匹配词。
- [x] 2.2 在知识库现有 RLS 与当前 READY 文件约束内检索候选片段，按字段命中、覆盖度和片段相关性排序，允许同一条目多个有用片段并保留定位。
- [x] 2.3 加入弱证据拒答与检索性能边界测试，验证无证据时不产生模型调用、普通知识库搜索行为不变。

## 3. 可核对回答

- [x] 3.1 调整模型提示与响应解析为有界的逐条结论及引用结构，限制输出大小和无依据回答。
- [x] 3.2 服务端逐条验证引用编号、片段依据、当前权限、条目 revision 和文件版本；异常、弱证据或资料变化时不发布事实结论。
- [x] 3.3 扩展回答 DTO，返回每条结论所对应的摘录、页/行定位和站内链接，并覆盖伪造引用、错误结构及版本变化测试。

- [x] 4.2 更新客服面板发送有界临时历史、显示逐条结论与原文摘录；清空、退出、撤权和刷新时删除上下文，保持纯文本渲染。
