## Context

博客前台基于开源 Ruyu/kuailemao 模板，品牌层已部分改为郑陆宇（`site.ts`、标题、部分外链），但仍有硬编码模板文案、打赏假数据、旧 CDN 鼠标样式，以及空壳/演示向模块，导致求职个人站观感像拷贝仓库。

约束：保留目录名与 Java 包名；以最小侵入改前台展示层；生产已通过 Nginx 部署在 `82.156.90.186`。

## Goals / Non-Goals

**Goals:**
- 访客第一印象是「郑陆宇的个人技术/求职站」，而非开源模板演示站
- 清理假打赏、模板 About 文案、旧图床光标等明显指纹
- 默认隐藏打赏等演示向侧栏；菜单对空能力保持克制（已有无音乐配置则隐藏播放器的逻辑继续沿用）

**Non-Goals:**
- 不重做整站视觉/设计系统
- 不重命名 `kuailemao-blog` / `xyz.kuailemao`
- 不在本变更中改后端 API 或强改数据库种子内容（网站信息由管理端手工更新）
- 不删除树洞/相册/友链等业务代码，仅调整默认可见性或文案入口

## Decisions

1. **文案集中到 `src/config/site.ts`（及少量页面常量）**  
   - 替代 About/欢迎语中散落的中二修仙文案与「小张」问候。  
   - 备选：全部改数据库网站信息——仍无法覆盖 About 硬编码；故以前端常量为准。

2. **打赏模块：清空假列表 + 默认不渲染侧栏打赏入口**  
   - 在 SideBar 中关闭 `ChargingList` 挂载（或配置开关 `SHOW_CHARGING=false`）。  
   - 备选：保留组件但空列表——侧栏仍占位，去模板效果差。

3. **鼠标样式：移除对 `image.kuailemao.xyz` 的 cursor url**  
   - 恢复系统默认光标，避免旧 CDN 404/品牌泄露。

4. **About 导航：保留一个 GitHub（主页），仓库链接改为文字或合并，去掉重复大图标**  
   - 简介改为简短求职向自我介绍（姓名、方向、可联系），去掉撒花强制触发可改为可选或删除。

5. **演示功能**：音乐保持「无 `VITE_MUSIC_SERVE` 则不展示」；树洞/相册若菜单写死，本变更仅去掉明显模板文案，菜单裁剪作为可选任务（默认：侧栏打赏关，About/问候必改）。

## Risks / Trade-offs

- [About 文案仍需用户确认最终措辞] → 任务中用占位求职文案，可在 apply 前微调  
- [隐藏打赏后若以后要开通] → 保留组件文件，用开关恢复  
- [网站信息仍是库内模板] → 部署检查清单要求管理端更新站名/头像/简介  

## Migration Plan

1. 合并前台改动 → 本机 `deploy-to-server.ps1 -Only blog`  
2. 管理端更新网站信息（站名、头像、备案号等）  
3. 回滚：还原相关 Vue/scss/site.ts 并重新部署博客 dist
