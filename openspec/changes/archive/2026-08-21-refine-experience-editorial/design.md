## Context
当前页面已具备完整数据和 Markdown 详情，但卡片时间线与圆形装饰接近模板风格。参考成熟设计作品集常见的超大标题、编号索引、横向项目行和案例研究式正文。
## Goals / Non-Goals
**Goals:** 更强视觉识别；更快扫描公司/职位/周期；详情阅读更沉浸；保持暗黑模式和移动端质量。
**Non-Goals:** 不新增数据字段，不修改后台内容模型。
## Decisions
1. 列表取消独立圆角卡片，使用整行分隔、巨大编号水印和 hover 色块，减少组件堆叠感。
2. 首屏采用左侧标题、右侧短宣言和统计，正文以连续索引承接。
3. 详情页使用左侧 sticky 项目档案、右侧 Markdown 长文，取消正文大卡片边框。
4. 使用现有 CSS 变量并限制动效，兼容暗黑主题与 reduced-motion。
## Risks / Trade-offs
- [条目内容过长] → 列表最多展示三条摘要并限制单行宽度。
- [移动端双栏拥挤] → 900px 以下改为单列并取消 sticky。
