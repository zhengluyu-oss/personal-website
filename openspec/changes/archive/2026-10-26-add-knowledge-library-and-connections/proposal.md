## Why

个人博客目前同时承载正式文章和零散学习笔记，影响对外展示与个人查阅。新增知识库承接笔记和参考文件，通过可解释的手动关系连接资料、概念与正式文章，形成“积累—关联—整理—发布”的流程，同时提供可演示、可测试的毕业设计扩展。

## What Changes

- 增加导航“知识库”，站主可新建/编辑 Markdown 笔记、维护分类标签、上传 PDF/Markdown/TXT 参考文件；普通访客按现有模块权限只读查看。
- 默认模块不公开、不授予普通角色；复用既有后台“前台模块访问”授权入口，不新增访客独立白名单。只有配置的站主可以管理，ADMIN 角色不自动取得写权限。
- 使用现有 PostgreSQL 实例中的独立 knowledge schema、独立低权限运行角色与小连接池，日记数据、事务和配置保持隔离。
- Java 复用 RabbitMQ 异步解析资料，保存页码/段落定位，提供任务进度、失败原因和有限重试；文件使用受保护的私有对象存储。
- 提供支持中文的关键词检索、分类标签筛选和结果定位；首版不调用模型，不生成向量，不增加语义检索和自动关联。
- 手动维护概念及“解释、依赖、参考、相关”关系，提供局部关系图和等价的列表入口，可关联现有且有权查看的博客文章。
- 选择笔记和资料片段，手工整理预览后创建独立博客草稿，保留来源快照与映射；不自动公开，不自动移动既有文章。
- 沿用 Vue、Spring Boot、Java、MySQL/PostgreSQL、OSS 和现有 RabbitMQ；不引入 Python、图数据库、独立搜索服务或新服务器。

## Capabilities

### New Capabilities
- `knowledge-library-workspace`: 知识库入口、站主管理、模块只读授权、笔记可靠保存、分类标签与独立 PostgreSQL 数据边界。
- `protected-knowledge-processing`: 私有文件上传/读取、版本化解析、可靠消息任务、失败恢复及单机资源约束。
- `knowledge-keyword-search`: 中文关键词、内容筛选、片段/页码定位及删除和权限即时生效。
- `knowledge-connections`: 概念维护、手动语义关系、受权限过滤的局部关系图与列表浏览。
- `knowledge-article-drafts`: 人工编排资料来源、创建幂等博客草稿、跨库失败恢复及独立内容生命周期。

### Modified Capabilities

无。现有文章发布、公开文件上传与日记契约保持；新功能的模块注册及草稿适配由上述新规格约束。

## Impact

- 前台新增知识库工作区和路由，复用现有编辑、分页、安全渲染、无权限框架与 ECharts；管理端现有角色模块授权增加知识库项。
- 后端新增 knowledge 领域包、接口、显式 PG 数据源/事务、迁移、私有存储适配、RabbitMQ 解析队列及本机 Java 文档解析程序；PDFBox 为拟新增 Java 解析依赖，实施前复核版本与依赖风险。
- PostgreSQL 新增 knowledge 表、约束和权限策略；MySQL 只新增草稿导出幂等映射表与模块初始策略，不迁移文章或日记。
- 私有文档不得复用直接返回永久公开 URL 的现有图片上传流程。按站主最新决定，复用现有 OSS Bucket 和服务器凭据；文件使用独立 knowledge 前缀和上传时明确设置的 private Object ACL，不改变现有公开媒体策略。仅在匿名访问 OSS 原域名及现有媒体域名都被拒绝后开放文件能力。
- 默认解析并发 1，限定大小、页数、时长和临时文件；部署前完成资源实测、双数据库备份恢复和本人授权验收。
- 此次仅生成规划，不修改业务代码、不安装依赖、不改变生产环境；保留工作区已有登录修复改动。
