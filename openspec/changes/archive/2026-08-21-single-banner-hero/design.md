## Context

首页当前从 Banner 接口读取多张图片，使用多个绝对定位元素做 30 秒淡入淡出轮播；品牌区叠加故障字、彩色短句、粒子和 SVG 波浪。新的内容策略只保留一张夕阳海岸图片，因此需要减少竞争性动画，转向稳定的电影感构图。

## Goals / Non-Goals

**Goals:**

- 第一张有效 Banner 始终满屏、稳定展示，无淡入淡出或轮播缩放。
- 通过纯 CSS 遮罩、光晕、暗角和底部渐变让文字清晰、画面有纵深。
- 品牌标题与动态短句成为明确焦点，向下引导自然连接首页正文。
- 移除 Wave 输出，并兼容移动端、低高度屏幕及减少动画偏好。

**Non-Goals:**

- 不修改图片内容或生成新图。
- 不修改 Banner 接口、后台管理和数据库。
- 不取消动态短句、粒子或平滑滚动能力。

## Decisions

1. `Images` 仅保存 `res.data` 中第一条非空地址，并渲染单个语义背景层；空数据时保留深色渐变后备背景。
2. 背景不做持续缩放，使用静态 `background-size: cover`；惊艳感来自多层径向/线性渐变、暗角、顶部导航对比和底部无缝过渡。
3. 品牌区移除 `TextGlitch`，改为轻量眉题、主标题、强调线与玻璃短句卡，避免故障动画破坏夕阳图的高级感。
4. 移除 `Wave` 组件实例，以底部渐变遮罩衔接正文；保留圆形向下按钮，但改为细线圆环和微弱呼吸效果。
5. 粒子层继续保留但由现有组件负责；新增样式不引入高成本滤镜动画，并在减少动画偏好下关闭位移和呼吸。

## Risks / Trade-offs

- [接口仍返回多图但前台只展示第一张] → 在提案中明确这是预期策略，后台将第一张作为主 Banner 管理。
- [不同宽高下图片主体被裁切] → 桌面使用居中，移动端调整 `background-position`，保证云层、海岸和棕榈树平衡。
- [浅色云层影响文字对比] → 文字区域叠加局部暗色径向遮罩和文字阴影，而不是全图重度压暗。

## Migration Plan

替换首页 Banner 与品牌区模板/样式，构建验证后部署前端静态资源。回滚只需恢复两个首页组件。
