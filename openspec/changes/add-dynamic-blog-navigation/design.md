## Context

桌面导航和移动抽屉是两个独立组件，分类接口已由分类页面使用。若两个导航分别请求，会产生重复网络请求。

## Goals / Non-Goals

**Goals:**
- 桌面和移动端显示一致的动态文章分类。
- 在单次页面生命周期中复用分类请求。
- 接口异常时不影响主导航使用。

**Non-Goals:**
- 不新增导航管理后台，不改变分类数据模型。

## Decisions

- 新增模块级共享 composable 缓存分类列表和请求状态，两个导航显式调用同一加载函数。
- 一级入口固定指向 `/category`，分类子项指向 `/category/:id`。
- 动态列表设定最大高度与滚动，防止分类过多撑出视口。

## Risks / Trade-offs

- [分类名称过长] → 子菜单限制宽度并使用省略显示。
- [接口失败] → 静默降级，仅展示固定的“全部栏目”入口。
