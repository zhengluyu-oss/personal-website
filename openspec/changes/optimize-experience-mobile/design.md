## Context

当前页面主要以桌面网格为基础，通过单个断点降级；手机端仍继承了过大的展示字体和依赖 hover 的交互。

## Goals / Non-Goals

**Goals:**
- 为 360–800px 视口建立内容优先的独立排版。
- 保证公司名、职位、时间和成果在首屏可快速扫读。
- 防止 Markdown 内容横向溢出并改善触控体验。

**Non-Goals:**
- 不改变桌面端视觉方向、数据接口或后台字段。

## Decisions

- 在现有组件内增加分层媒体查询，避免复制移动端组件和逻辑。
- 列表项使用两列移动网格，编号作为轻量视觉锚点，成果摘要限制行数。
- 详情页将档案改为紧凑网格，正文对代码和表格提供局部横向滚动。
- 使用 `:active` 和 `focus-visible` 补足无 hover 设备的交互反馈。

## Risks / Trade-offs

- [超长公司名仍可能占据多行] → 使用断词规则和更保守的流体字号。
- [Markdown 表格宽度不可控] → 允许正文内部滚动而不推动整个页面。
