# 博客主推荐配置部署说明

## 部署顺序

1. 备份生产数据库中的 `sys_website_info` 与 `t_category` 表。
2. 执行 `sql/configurable-blog-featured-articles.sql` 的向前迁移部分。
3. 部署后端服务，确认 `/article/blog-feed` 可以在未配置推荐文章时返回最新公开文章。
4. 部署管理端与博客前端。
5. 在“网站管理 → 信息管理”选择聚合页主推荐文章，并在分类管理中按需选择分类主推荐文章。

## 上线验证

- `/blog` 展示后台选择的聚合页主推荐，且下方列表不重复。
- 每个 `/blog/:slug` 展示各自选择的分类主推荐。
- 清空配置后自动回退到对应范围最新公开文章。
- 把配置文章改为草稿后，公开页面自动回退且不泄露草稿。
- 将分类主推荐文章移动到其他分类后，原分类自动回退。
- 没有公开文章的分类显示空状态。

## 回滚

先回滚博客前端、管理端和后端应用。新增字段均可为空，可以暂时保留；确认不再需要后，再执行迁移脚本末尾注释中的回滚语句。不要在应用回滚之前删除字段。
