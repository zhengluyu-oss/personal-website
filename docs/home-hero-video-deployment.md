# 首页背景视频上线核对

视频文件由管理员浏览器直接上传至 OSS，访客从 `https://media.zhengluyu.com` 直接读取；不经博客服务器，也暂不接入 CDN。2026-10-11 已完成生产数据库迁移、私有播放域名配置及后端、前后台发布；尚未由管理员上传正式首页视频，首页仍显示图片封面。

## 现状与最小配置

- 现有 Bucket 默认域名可公开读取 Banner 图片并支持 `Accept-Ranges: bytes`，但响应有 `x-oss-force-download: true` 与附件下载头，不能用作可靠的网页视频播放地址。
- OSS 已配置允许 `https://www.zhengluyu.com` 的 POST 跨域；2026-10-11 预检返回 200，包含正确的允许来源、方法和请求头。
- `media.zhengluyu.com` 已绑定 OSS、自定义 CNAME 和 HTTPS 证书；公开图片验证返回 200、支持范围请求，且无强制下载头。正式视频上传后仍需核对 MP4 的响应头和浏览器播放。域名直连 OSS，未开启 CDN。
- 当前托管的是个人测试证书，预计 2027-01-09 到期；到期前需重新签发并更新 OSS 托管证书，避免视频因 HTTPS 证书失效而无法播放。
- 现有上传凭据已用随机测试 MP4 验证该前缀的 PutObject、HeadObject 和 DeleteObject 均可用，测试对象已删除。后端可用该凭据本地签发 PostObject Policy；正式上线仍需从浏览器验证策略与 CORS。RAM 权限建议收窄到 `blog/home/hero-video/*` 所需操作，避免给予整个 Bucket 的无关管理权限。
- CORS 允许来源为 `https://www.zhengluyu.com` 和 `https://zhengluyu.com`，允许 `POST` 和请求头 `Content-Type`，暴露 `ETag`。不要使用 `*` 来源或允许携带长期密钥。
- 后端私有配置已设置 `oss.media-domain: https://media.zhengluyu.com`。长期 AccessKey/SecretKey 保持在现有私有配置或环境变量中，不能写入仓库或浏览器。

## 上线顺序

1. 备份 `sys_website_info`，在生产 MySQL 执行 [`sql/home-hero-video.sql`](../sql/home-hero-video.sql)。该脚本重复执行安全；新增字段可空，原有记录为空时仍显示第一张 Banner 图片。
2. 在 OSS 完成自定义域名、HTTPS、DNS、CORS 和 RAM 权限配置；从浏览器确认上传预检、直传与公开读取均正常。当前上限为 100 MB（100,000,000 字节），上传策略有效 30 分钟；确认范围请求和 `video/mp4` 元数据。
3. 配置后端 `oss.media-domain`，部署后端，再部署后台与前台。先在“首页轮播图”页面上传短 MP4，确认后台预览与首页封面、视频、暂停按钮正常。
4. 用桌面与 360/390/430/640px 宽移动端检查文案可读性及无横向滚动；在省流量/减少动态效果和 3 Mbps 冷缓存下确认封面可先显示。上线后观察 OSS 下行流量和费用。

## 回滚

先在后台移除视频，让首页立即回到第一张 Banner 图片；再回滚前台与后台版本。数据库字段可以暂时保留，不影响旧版本。若必须删列，确认视频配置已清空、完成备份后执行迁移脚本末尾的 `DROP COLUMN` 语句。OSS 对象清理须先确认无引用，避免误删仍在播放的媒体。

## 本地验证记录

- 后端视频服务、后台权限及网站信息兼容测试通过；前后台构建通过。前台初始资源为 JS 128.4 KB、CSS 9.5 KB（gzip），仍在既有预算内。
- 首版上线前曾使用 8 MiB、五分钟签名策略向 OSS 发起表单 POST，返回 200；对象元数据正确，测试对象已删除。2026-10-12 将限制改为 100 MB、30 分钟签名策略，需重新核验新策略与浏览器直传。
- 桌面与 360/390/430/640px 视口检查了首页封面、文案和按钮。本地 4.3 MB 测试 MP4 可播放；滚出首屏暂停、返回恢复，手动暂停后不会擅自恢复，且滚动时不移除视频源造成重复下载。
- 模拟 3 Mbps 冷缓存时先呈现文字和静态封面，再开始视频；阻断视频请求或启用减少动态效果后仍保留图片、文字和操作入口。
- GitNexus 将整组改动评为 critical，原因是 `WebsiteInfo` 的新增数据库字段波及网站信息公开读取等 25 条执行流。生产环境已先备份并执行可空字段迁移，再部署后端和前台；公开网站信息接口返回 200，包含 `heroVideoUrl: null`。后台接口在未登录时正确拒绝访问。正式视频的浏览器直传与播放仍待管理员上传素材后核验。
